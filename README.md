# Puc_Fit

Sistema de **gerenciamento de saúde e bem-estar** executado no terminal, desenvolvido em Python como projeto acadêmico na PUCPR. O objetivo foi praticar lógica de programação, validação de entrada e organização de fluxo em um programa interativo completo.

## ✨ Funcionalidades

- **Cadastro e login** do usuário no início da execução
- **Cálculo de IMC** a partir do peso e altura informados
- **Meta de hidratação** diária personalizada
- **Estimativa de gasto calórico**
- **Sugestões de dieta e treino** conforme a meta definida
- **Validação de todas as entradas** — peso e altura inválidos são recusados até o usuário digitar um valor válido

## ▶️ Como executar

Requer apenas Python 3 — nenhuma dependência externa.

```bash
git clone https://github.com/EduardoLopessz/Puc_Fit.git
cd Puc_Fit
python PucFit_final.py
```

O programa é interativo: siga as instruções exibidas no terminal.

## 🛠️ Tecnologias

Python 3 · biblioteca padrão apenas · interface via terminal

## 💡 O que aprendi

Este projeto me obrigou a pensar no **fluxo completo** de um programa, não só em funções isoladas: manter o usuário dentro de um laço até que a entrada seja válida, guardar estado entre etapas (IMC calculado, meta definida) e encadear as decisões que dependem desses dados.
